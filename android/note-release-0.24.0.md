APK per Android (arm64, Android 8 o successivo).

## Novità della 0.24.0

- **Nuova grafica**: dall'icona si apre la finestra del tema scelto, come sul computer (Essenziale, Percorso guidato, Compatto, Banco di lavoro, Documento al centro). Ogni tipo di file e ogni attività ha il suo colore. Ogni tema usa il suo carattere, e in Aspetto si può scegliere fra caratteri Normali e Grandi.
- **PDF**: in Excel, Unisci (più PDF, anche condivisi insieme, ordine col trascinamento), Dividi (con le miniature), Pagine (ruota, togli, sposta, numeri, filigrana), Comprimi. I PDF con password si aprono dopo averla inserita.
- **Rivedi trascrizione**: frasi col tempo e audio che si sente, «Segui l'audio», punti da controllare, «Sistema tutte le ripetizioni», salvataggio in TXT, SRT o VTT, riapribile dai Lavori.
- **Altre opzioni**: gli stessi formati e opzioni del computer (FLAC, Opus, AIFF, AVIF, JPEG XL e altri; canali, normalizza, taglia silenzio, risoluzione video…).
- **ZIP**: le foto, gli audio e i documenti degli ZIP condivisi si convertono. Più file condivisi insieme finiscono in un solo ZIP.
- **Impostazioni**: nome del file a modello con esempio, cosa fare se il file esiste già, qualità, DPI, lingua e pagine dell'OCR.
- **Ultimi file**: i file usati di recente si rimettono in coda con un tocco.
- Corretto: tutti i file di un lavoro (per esempio i pezzi di Dividi) arrivano in Documenti/Cedro; «Apri» sui file Excel.
